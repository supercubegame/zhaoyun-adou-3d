# 3D asset integration notes

- Runtime format: glTF/GLB.
- Loader: Three.js `GLTFLoader`.
- Expected future paths: `assets/models/zhaoyun.glb`, `assets/models/adou.glb`, `assets/models/enemy.glb`, `assets/models/environment.glb`.
- Every model must be listed in `assets/manifest.json` with source, license, download date, and usage note.
- The current preview intentionally uses procedural placeholder geometry. It is not a final character model.
- Do not copy the reference App's character art, UI, screenshots, or audio.
