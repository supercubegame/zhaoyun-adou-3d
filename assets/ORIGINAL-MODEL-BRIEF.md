# 原创角色与动画制作单

## 赵云

Low-poly stylized Chinese Three Kingdoms cavalry hero, blue-gray armor, warm gold sash, spear, readable silhouette from a high isometric camera. Animations: idle, walk, attack, hit, protect, victory, defeat.

## 阿斗

Low-poly stylized child prince, blue robe, small gold ornament, protected silhouette, no weapon. Animations: idle, follow, scared, rescued, defeat.

## 敌军

Low-poly stylized generic armored raider, dark red cloth, muted metal, intentionally generic and not copied from any reference game. Animations: idle, walk, attack, hit, defeat.

## Delivery format

- glTF/GLB
- one model per character
- embedded or relative textures only
- animation clip names exactly match `ANIMATION_STATES` where applicable
- include preview render and source/license note before shipping
