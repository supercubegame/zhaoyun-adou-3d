# zhaoyun-adou-3d

## Gate first

Before feature code, `npm run verify` must return exit code 0 and print a readable result.

## Project shape

This is a browser-based top-down 3D game. Keep game rules in pure modules where possible. Browser rendering and input belong in the slow gate; deterministic rules belong in the fast gate.

## Evidence rules

A green gate proves only the assertions it names. Human checks remain separate: visual quality, controls, touch feel, audio audibility, and playability.

## Scope

The first playable slice is Zhao Yun protecting A Dou through a short top-down 3D route. Do not add monetization, external accounts, or production secrets.
